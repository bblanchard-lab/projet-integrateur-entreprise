# projet-integrateur-entreprise
Ce projet consiste à monter de zéro l'infrastructure réseau d'une entreprise multi-sites (Citadelle Solutions) sous Windows Server. L'objectif était de mettre en place un annuaire Active Directory propre, de gérer la sécurité des accès selon les bonnes pratiques et de déployer un serveur de fichiers centralisé avec mappage automatique.
